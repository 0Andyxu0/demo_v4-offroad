## 一、 核心命题与范式转移：越野有人驾驶宏观规划的真实需求定界

在传统地面移动机器人（UGV）越野规划领域，主流学术成果大多默认以“无人自动驾驶底盘”为受控对象。这一假设直接导致算法极度侧重于**车载实时高精传感器避障、无人机伴随协同与高阶平滑轨迹生成（Dubins/B 样条/多项式平滑）**，并追求标量代价图上的数学最短。

然而，将该套范式直接套用于**大尺度野外有人驾驶（Manned Off-Road Navigation）**时，会引发灾难性的工程与体验断层。必须实现以下范式转移：

```
[传统文献/无人车导航偏向]
  - 核心假设: 车辆无智能, 缺乏前瞻感知, 必须输出亚米级 C1/C2 连续平滑轨迹, 严格受控转向半径;
  - 感知手段: 依赖车载 3D LiDAR/相机实时在线建图, 或无人机空中伴随侦察链路 (Patel 2024, Hu 2026);
  - 优化目标: 纯标量图搜索数值最优 (Shortest Path / Minimum Cost);
  - 实际痛点: 遇到 1.5m 贴崖小道照走不误; 1km 内反复切换 5 种地表导致驾驶员疲惫崩溃; 暴雨后低洼翻浆托底。

===================================================================================================

[本次定义的真实科学命题: 越野环境有人驾驶宏观全局规划]
  - 核心输入: DEM (高程/坡度/粗糙度) + 地物要素 (矢量 SHP/栅格 TIF) + 遥感影像 + 土壤本底 (USCS) 与含水率 + 
              【制作静态地图时的真实气象降雨与前期降水指数 (API) 修正】;
  - 驾驶员特性: 具备 20~50m 前向通视滤波能力、微观避障能力与自然操舵平滑本能;
  - 放宽条件: 【完全允许路线呈现 H3 离散格网性质导致的频繁折线 (60°/120° 折角)】, 彻底免除高阶轨迹平滑算力开销;
  - 核心收紧: 【极度关注路线整体质量 (Route Overall Quality)】:
              1. 走廊有效通行宽度与横向容错裕度 (坚决杜绝紧贴悬崖或树木的“独木桥式险道”);
              2. 地表介质连续性与频繁换地惩罚 (抑制高频换挡、锁差速器与操舵心理负荷);
              3. 地形骨架线顺应度 (沿等高线阶地、缓坡、山脊线顺势展线, 符合老司机直觉);
              4. 前瞻通视视距与盲坡规避 (规避冲顶后垂直断坎与视觉盲区);
              5. 暴雨汇水翻浆软化土沉陷托底红线 (水文动力学耦合 Bekker 沉陷一票否决).
```

## 三、 5 篇核心文献深入解析与面向有人驾驶的局限

### 3.1 文献 1：Wu et al. (2024)
- **题目**：*A hierarchical model with hexagon grids for multi-objective route planning in large-scale off-road environments*
- **出处**：*International Journal of Geographical Information Science (IJGIS)*, 38(7): 1388–1413. [DOI: 10.1080/13658816.2024.2347319](https://doi.org/10.1080/13658816.2024.2347319)
- **技术方法**：使用 Uber H3 离散六边形划分连续空间；以相邻六边形通行力差异 $\|Grid(n_1)-Grid(n_2)\| \le q$ 为判据，合并同质单元为宏观多边形；以边界共享边中点构建新邻接图，运行改进的多特征启发式 NAMOA* 搜索 Pareto 路径。
- **优点与借鉴**：证明了 H3 离散六边形在宏观大尺度越野建模中具有距离各向同性、邻域拓扑一致（均为 6 个等距邻居）的巨大优势；提出了基于相似性聚合减少搜索图规模的思路。
- **面向有人驾驶的局限**：
  1. *无地面力学量纲*：通行力仅靠土地覆盖面积占比的人工加权，缺乏轮-土力学机理；
  2. *坡度绝对值标量化*：未区分上坡克服动力阻力与侧坡翻车风险；
  3. *纯静态无气象*：未建模降雨入渗与微地形土壤软化；
  4. *单线搜索忽略走廊*：输出离散中心单折线，未评估两翼横向净空与驾驶员综合负荷。

### 3.2 文献 2：Zhou et al. (2026)
- **题目**：*An unstructured roadless environment navigation map construction method based on remote sensing*
- **出处**：*Geo-spatial Information Science (GSIS)*, 29(3): 1897–1918. [DOI: 10.1080/10095020.2025.2570025](https://doi.org/10.1080/10095020.2025.2570025)
- **技术方法**：融合高分遥感正射影像与 DEM 生成高精度不规则三角网（TIN）；根据用户输入的车辆通行阈值（最大坡度、障碍高度、禁行地类）二值化可行域；采用 Weiler-Atherton 算法消除多孔多边形内洞，耳切三角剖分（Ear-Clipping）生成导航网格（NavMesh），在三角网对偶图上运行 A*。
- **优点与借鉴**：突破栅格离散限制，将可行域矢量化为紧凑的多边形导航网格；体现了面向不同底盘交通能力定制导航图的思想。
- **面向有人驾驶的局限**：
  1. *二值化硬截断误杀关键走廊*：“非黑即白”的二值化将大量“虽难行但降速可通行”的重要通道彻底剔除；
  2. *碎小多边形拓扑爆炸*：自然越野地貌的植被边界导致耳切法生成数万碎小三角形，拓扑维护代价极高；
  3. *无气象力学响应*：纯几何阈值，低洼积水翻浆完全失察；
  4. *实验区域微小*：仅在 $1\text{km} \times 0.7\text{km}$ 区域验证，无法胜任数十公里长途战术机动。

### 3.3 文献 3：Patel et al. (2024)
- **题目**：*RoadRunner M&M - Learning Multi-Range Multi-Resolution Traversability Maps for Autonomous Off-Road Navigation*
- **出处**：*IEEE Robotics and Automation Letters (RA-L)*, 9(12): 11425–11432. [DOI: 10.1109/LRA.2024.3490404](https://doi.org/10.1109/LRA.2024.3490404)
- **技术方法**：针对 DARPA RACER 高速越野无人车，构建端到端多尺度网络（近距 $\pm50\text{m}@0.2\text{m}$，远距 $\pm100\text{m}@0.8\text{m}$）；输入 4 路图像 + LiDAR 体素，后验融合 X-Racer 与卫星 DEM 自监督，下游接入 MPPI 动力学控制器。
- **优点与借鉴**：揭示了越野感知的尺度金字塔规律（近处高精、远处大范围）；引入卫星 DEM 作为远距离空间先验。
- **面向有人驾驶的局限**：
  1. *感知视野局限（$\le 100\text{m}$）*：属于车载近场反应式避障，无法承担出发前数十公里宏观全局选线；
  2. *设备功耗高*：依赖高功耗 GPU 与激光雷达，不符合离线静态地理制图规范；
  3. *无大尺度水文力学*：纯几何与纹理推断，无法预测降雨后深层土壤承载力衰退。

### 3.4 文献 4：Hu et al. (2026)
- **题目**：*Satellite–UAV Collaborative Off-Road Traversability Mapping and Incremental Updating for Unmanned Ground Vehicles*
- **出处**：*Remote Sensing*, 18(17): 3045. [DOI: 10.3390/rs18173045](https://doi.org/10.3390/rs18173045)
- **技术方法**：构建先验层（卫星/DEM/土壤/OSM）、语义层与通行代价层三层 H3（H3-12/13）格网；无人机前出空中侦察，采用观测者无关的固定格网 Override 机制局部覆写代价，触发 A* 增量重规划。
- **优点与借鉴**：规范了以 H3 为核心的异构多源地理空间数据分层融合范式；提出了“软代价+有限硬代价”平衡全局连通性与局部避障。
- **面向有人驾驶的局限**：
  1. *强依赖空中伴随无人机*：在无无人机协同的独立装备机动中无法闭环；
  2. *土壤层为静态定性分类*：未建立降雨径流对土壤抗剪强度的软化物理模型；
  3. *单点搜索忽略走廊*：未评估通行走廊横向裕度与地表切换疲劳。

### 3.5 文献 5：Eder et al. (2023)
- **题目**：*Traversability analysis for off-road environments using locomotion experiments and earth observation data*
- **出处**：*Robotics and Autonomous Systems*, 168: 104494. [DOI: 10.1016/j.robot.2023.104494](https://doi.org/10.1016/j.robot.2023.104494)
- **技术方法**：采集阿尔卑斯山地 4 种地面机器人实车运载动力学数据（IMU 振动、能耗、滑移率、车速）；利用 Sentinel-2 遥感影像与 DEM 聚类生成多维地表类，建立遥感特征到运载物理代价的映射与线性插值外推。
- **优点与借鉴**：实证了宏观地球观测（EO）遥感数据可直接映射为车辆实测运载力学代价；将滑移、能耗、振动纳入真实物理量纲。
- **面向有人驾驶的局限**：
  1. *经验查表无外推能力*：缺乏跨地质区域的力学机理迁移性，换场地需重新做实车测试；
  2. *仅假定干燥晴天*：完全缺失降雨与土壤湿度耦合动态；
  3. *有图无规划器*：仅产出 Costmap，未解决复杂多目标网络寻优、走廊提取与质量控制。

   - 在 [`src/h3_offroad_planner/route_planning.py`](file:///d:/Workspace/demo_v4/src/h3_offroad_planner/route_planning.py#L557-L560) 中，默认规划会同步调用 [`src/h3_offroad_planner/dynamics/trajectory_geometry.py`](file:///d:/Workspace/demo_v4/src/h3_offroad_planner/dynamics/trajectory_geometry.py) 计算车辆圆弧切线元（`TrajectoryPrimitive`）与整车扫掠包络；
   - **后果**：由于 H3 离散六边形天然具有 60°/120° 折角，在细格网间强制拟合实车转弯半径，导致有效 H3 候选路线频繁触发 `TURNING_SPACE_INSUFFICIENT` 错误；在 [`src/h3_offroad_planner/candidate_aggregation.py`](file:///d:/Workspace/demo_v4/src/h3_offroad_planner/candidate_aggregation.py#L380-L395) 中因 `valid` 集合为空而报 `NO_GEOMETRY_VALID_CANDIDATE` 警告并回退。有人驾驶宏观导航完全可接受格网折线，现场操舵由驾驶员平滑完成。
2. **铺装道路与天然土壤混同，以及地表结构参与不足**：
   - 现有逻辑若仅在粗格网标记一个 `has_road` 属性，容易造成两种极端：要么让整格免受水体或断路障碍约束，要么让下伏土壤类型把硬化公路误判为泥地；
   - 必须按真实铺装范围采用路面通行模型，天然地面按土壤力学模型，互不干扰。
3. **绕行预算基准不一致**：
   - [`candidate_aggregation.py`](file:///d:/Workspace/demo_v4/src/h3_offroad_planner/candidate_aggregation.py#L380) 当前使用的绕行基准来自局部候选池中的最短长度，而非全图基准图上的全局最短 $L_{\min}$，导致绕行约束的物理含义产生漂移。

### 5.1 理论创新 1：地表结构与气象水文修正的通行地图构建

1. **铺装道路矢量缓冲与天然土壤力学的物理严格分离**：
   - 彻底废除简单的格元级 `has_road` 布尔掩码覆写。读取 `road_fina.shp`，根据宽度属性代码映射真实宽度（`"30"` 对应 $3.5\text{ m}$，`"55"` 对应 $5.5\text{ m}$，默认 $3.5\text{ m}$）；
   - 在高精米制投影坐标系下对道路中心线执行 `buffer(W_road / 2.0)`，生成连续铺装道路多边形面集 $\mathcal{P}_{\text{paved}}$；
   - **物理模型解耦隔离**：若 H3 格元与 $\mathcal{P}_{\text{paved}}$ 的相交面积占比 $\alpha_{\text{paved}} \ge 0.5$，强制激活硬化路面物理模型（高附着 $\mu=0.85$、低滚动阻力 $f_r=0.015$），并**豁免天然降雨下渗与土壤软化沉陷**；其余格元严格执行 USCS 土壤与降雨下渗力学，彻底消灭“沥青路面被下伏泥土算成泥沼”或“一截公路导致整格悬崖与深水被误标为平路”的覆写冲突。
2. **制图期真实气象时序与微地形水文耦合**：
   - 在静态制图编译阶段，输入出发前 $N=3\sim 7$ 天的历史降雨序列 $P_t$（mm），计算前期降水指数 $API = \sum_{t=1}^{N} k^{t} P_t$（$k=0.88$）；
   - 结合 DEM 比汇水面积与坡度派生 $TWI = \ln(\alpha / \tan \beta)$ 及相对排水高程 $HAND$，解算制图期有效体积含水率 $\theta_{\text{eff}}(h)$；
   - **接口规范**：计算所得 $\theta_{\text{eff}}(h)$ 直接以体积含水率（$\text{m}^3/\text{m}^3$）传入主干 [`vectorized_soil.py:26`](file:///d:/Workspace/demo_v4/src/h3_offroad_planner/vectorized_soil.py#L26)，制图完成后冻结物理状态，不产生在线计算负担。
3. **轮土力学单位统一与过饱和“空值逃逸”熔断修复**：
   - **单位严格归一**：轮胎接地压强统一为 $\text{kPa}$，轮宽 $b$ 统一为米（$\text{m}$），消除原有微米级沉陷计算误差；
   - **渐近软化与过饱和安全兜底**：查验发现主干采用线性回归公式在 $\theta \ge 0.45$ 时刚度模量 $k_c$ 衰减为负数，导致沉陷返回 `None` 并绕过门禁判定（Silent Pass）。本方案引入渐近刚度下限（$k_c \ge 15.0\text{ kPa}\cdot\text{m}^{1-n}, k_\phi \ge 50.0\text{ kPa}\cdot\text{m}^{-n}$）；并在含水率溢出或回归失效时，**强制赋值 $z_0 = \infty$**，坚决触发 `SINKAGE_CLEARANCE_EXCEEDED` 阻断，根除暴雨泥沼漏检隐患；
   - 沉陷阻断阈值：当 $z_0(h) \ge 0.8 \times \text{ground\_clearance} = 180\text{ mm}$ 时，格元置为不可通行。
4. **纵横坡严格解耦与抗侧倾安全机制**：
   - 针对行进有向边 $e=(u,v)$，位移向量为 $\vec{d}_{uv}$，局域高程梯度为 $\nabla z$。解耦计算纵向坡度比与横向侧倾角：
     $$i_{\text{long}} = \frac{\nabla z \cdot \vec{d}_{uv}}{\|\vec{d}_{uv}\|}, \quad \theta_{\text{pitch}} = \arctan(|i_{\text{long}}|)$$
     $$\theta_{\text{roll}} = \arctan\left( \frac{\|\nabla z \times (\vec{d}_{uv} / \|\vec{d}_{uv}\|)\|}{\sqrt{1 + i_{\text{long}}^2}} \right)$$
   - *平坡反例澄清*：在 $20^\circ$ 陡坡上沿等高线横切，纵坡为 $0^\circ$，但横向侧倾角直接高达 $20^\circ$（极易触发车辆侧翻）；垂直爬坡时纵坡虽达 $20^\circ$，横坡却为 $0^\circ$。算法同时评价纵坡动力克服（$F_{\text{grade}} \le F_{\text{max}}$）与横坡侧翻安全（$\theta_{\text{roll}} \le 15^\circ$），彻底纠正“沿等高线走天然更安全”的片面偏好。

### 5.2 理论创新 2：保留真实通道的区域—端口分层走廊表示

1. **PortsMap 拓扑实质澄清与 $(L, Q)$ 帕累托代表元保留**：
   - 主干 [`portsmap.py`](file:///d:/Workspace/demo_v4/src/h3_offroad_planner/portsmap.py) 的宏观节点本就是边界 Port 细格元，内部边由细层 Dijkstra 生成，物理断开的区域天然不连通；
   - **真正的结构性缺陷**：主干 [`offline_pairs.py`](file:///d:/Workspace/demo_v4/src/h3_offroad_planner/offline_pairs.py) 仅支持单 profile 存储单条标量最优路径，导致宏观搜索丢失了非凸折中候选；
   - **解决方案**：升级离线端口对表结构，持久化存储 $2\sim 4$ 条非支配 $(L, Q)$ 帕累托代表元路径及其瓶颈净宽，为宏观受约束选线提供无损备选支撑。
2. **源地表通行域格内通行片段（In-Cell Passage Patches，天然窄道 0 误杀保全）**：
   - 彻底废除依赖格元中心点采样净宽的判定机制（实证表明：在倾斜通过六边形的 3.0m 直通道内，17 个六边形中心点净宽全部小于 1.25m 导致通过率为 0）；
   - 严格遵守时序规范：先在连续几何空间对源通行域（矢量道路、峡谷垭口可行域）沿边界向内腐蚀半车宽（$-W_{\text{veh}}/2 = -1.028\text{m}$），生成可行通行核（Traversable Kernel）；
   - 将通行核与实际 H3 六边形求交，生成格内通行多边形片段（In-Cell Patches）；
   - 相邻格元内的片段沿 H3 共享边界距离小于 $1\times 10^{-6}\text{m}$ 建立细图无向边，并附带真实边界欧氏净宽 $d_{\text{clear}}$；
   - 栅格 EDT 仅作为开阔区宏观引导场，瓶颈通道严格以格内片段拓扑连通，彻底保全 3.0m 可用窄道。
3. **车辆通过性门槛与开阔度偏好解耦**：
   - 实车宽 $2.056\text{ m}$，硬几何门槛设为 $W_{\min} = 2.5\text{ m}$，使 $3.0\text{ m}$ 可用窄路保持物理连通；
   - 目标安全走廊宽度 $W_{\text{req}} = 15.0\text{ m}$ 作为软偏好引入质量函数，在存在绕行空间时优先引导有人驾驶选择开阔平稳通道。
4. **突破固定 1-ring 剪枝陷阱（多骨干走廊探索）**：
   - 1-ring 仅作为粗图检索的初始加载窗口；系统在粗层保留多条低代价、不同拓扑分支的骨干走廊，并在有限窗口遗漏重要候选或细层局部不可行时，支持自适应向外扩展瓦片，杜绝因过早剪枝丢失优质路线。

### 5.3 理论创新 3：有限绕行预算下的物理里程积分质量目标（ROQI）与 WCSPP 求解

1. **明确且统一的全局绕行预算定义**：
   - 严格以全场景基础图上的全局无约束物理最短距离 $L_{\min}$ 为基线，定义容许绕行预算集合：
     $$\mathcal{P}_{\text{feasible}} = \left\{ P \mid L(P) \le (1 + \delta) L_{\min} \right\}, \quad \delta \in [0.10, 0.25] \text{ (默认 0.15)}$$
   - 在满足该几何里程上界的空间内求解综合质量劣势最小化：$\min_{P \in \mathcal{P}_{\text{feasible}}} Q(P)$。
2. **物理里程连续积分代价（消除离散采样敏感性）**：
   - 质量代价严格定义为沿路线实际物理弧长 $s$ 的连续积分：
     $$Q(P) = \int_{0}^{L(P)} \left[ w_w \cdot c_{\text{narrow}}(s) + w_r \cdot c_{\text{roll}}(s) + w_s \cdot c_{\text{soft}}(s) + w_g \cdot c_{\text{rough}}(s) \right] ds + \sum_{k} \kappa(S_k, S_{k+1})$$
     - **狭窄段罚分** $c_{\text{narrow}}(s) = \max\left(0, \frac{W_{\text{req}} - 2 d_{\text{clear}}(s)}{W_{\text{req}} - W_{\min}}\right)^2$；
     - **横坡侧倾罚分** $c_{\text{roll}}(s) = \max\left(0, \frac{\theta_{\text{roll}}(s) - 10^\circ}{22^\circ - 10^\circ}\right)^2$；
     - **地表软化与粗糙罚分** $c_{\text{soft}}(s) = \left(\frac{z_0(s)}{0.8 \times \text{ground\_clearance}}\right)^2$，$c_{\text{rough}}(s) = \frac{TRI(s)}{TRI_{\max}}$；
     - **地表转换惩罚** $\kappa(S_k, S_{k+1})$：按连续地物斑块边界统计类型转换，抑制高频切换地表带来的频繁换挡与差速锁操作。
3. **最长连续困难段显式监控**：
   - 算法显式提取并导出“最长连续困难路段长度”（Longest Continuous Difficult Segment, LCDS），防止局部极长的高危狭窄或泥泞路段被全局平缓路段的积分总分所掩盖。
4. **受约束最短路（WCSPP）双向 Pulse 算法严格求解**：
   - 废除单节点局部贪心选边逻辑（贪心选边会导致前期挥霍预算、后期死锁）；
   - 引入双向脉冲算法（Bidirectional Pulse Algorithm, Cabrera et al. 2020）：
     - 预计算反向距离下界 $\underline{L}(v, t)$ 与质量下界 $\underline{Q}(v, t)$；
     - 宏观搜索遍历端口对帕累托代表元，执行**不可行剪枝**（$l + L_k + \underline{L} > (1+\delta)L_{\min}$）、**界限剪枝**（$q + Q_k + \underline{Q} \ge Q^*$）与**历史支配剪枝**；
   - 算法性质客观定性：WCSPP 在离散图上为弱 NP-hard 问题，Pulse 算法为基于分支定界剪枝的高效求解器，在离线摘要支撑下实现工程毫秒级响应。
5. **动态按预算补查机制（Scale-Invariant Budget-Aware Refill）**：
   - 宏观搜索遍历边 $e=(u, v)$，已知剩余长度预算 $B_{\text{rem}} = (1+\delta)L_{\min} - l_u - \underline{L}(v, t)$；
   - 触发补查判据：该端口对在离线时曾被截断（`is_truncated = True`），且缓存中满足 $L \le B_{\text{rem}}$ 的候选均满足相对质量缺额 $(Q_{\text{cache}} - Q_{\text{lb}}) / \max(1.0, Q_{\text{cache}}) > \epsilon_{\text{rel}}$（默认 0.10，无量纲指标）；
   - 触发后在细图上以 $B_{\text{rem}}$ 为约束执行局部双向搜索补入新非支配解，杜绝量纲缩放导致的漏查。

### 7.2 实验对比基线（Baselines）
1. **Baseline 1（代表文献 1，Wu et al. 2024 IJGIS）**：无气象修正、坡度标量化、无走廊宽度评价的 H3 NAMOA*；
2. **Baseline 2（代表文献 2，Zhou et al. 2026 GSIS）**：二值硬阈值截断 + 导航三角网格（NavMesh）A* 规划；
3. **Baseline 3（项目主干 baseline，demo_v4 master 986bd58）**：未解耦纵横坡、未接入制图期气象有效含水率、无连续净宽评价与走廊约束的加权多目标规划器；
4. **Proposed Method（W-HQ-Planner）**：铺装与土壤分离 + 制图期气象水文修正 + 区域端口分层走廊保留 + 绕行预算下里程积分综合质量优选。

### 7.3 核心量化评价指标
| 指标名称 | 物理与业务含义 | 计算公式与单位 |
| :--- | :--- | :--- |
| **走廊瓶颈通行净宽 ($W_{\text{margin}}$)** | 路线沿线最小真实障碍间距，证明路线是否具备人类驾驶的横向容错裕度。 | $2 \cdot \min_{s \in P} d_{\text{clear}}(s)$ (米, m) |
| **横坡侧倾超标里程比率 ($R_{\text{roll}}$)** | 路线中车辆侧倾角 $\theta_{\text{roll}} > 10^\circ$ 的高危路段在总里程中的占比。 | $\frac{\int_{P} \mathbb{I}(\theta_{\text{roll}}(s) > 10^\circ) ds}{L(P)} \times 100\%$ (%) |
| **雨后翻浆最大沉陷量 ($z_{\max}$)** | 在出航前降雨工况下，路线沿线轮土沉陷深度的最大值（熔断红线为 180mm）。 | $\max_{s \in P} z_0(s)$ (毫米, mm) |
| **地表介质切换频次 ($F_{\text{switch}}$)** | 单位里程内地表物理覆盖类型跳跃次数，直接反映驾驶员换挡与工效负荷。 | $\frac{\text{Switch Count}}{L(P)}$ (次/km) |
| **最长连续困难路段 ($D_{\text{diff}}$)** | 路线沿线连续处于狭窄（$<6\text{m}$）或高阻力湿软地表的单段最大物理长度。 | $\max \text{Length}(\text{Difficult Segment})$ (米, m) |
| **全局绕行比率 (Detour Ratio)** | 相比全场景统一基准图上无约束物理最短路线 $L_{\min}$ 的冗余度。 | $\frac{L(P) - L_{\min}}{L_{\min}} \times 100\%$ (%) |
| **端到端求解耗时 (Latency)** | 验证两阶段分层架构与离线摘要的工程响应速度。 | 秒 (s) |

### 7.4 典型实验情景与消融实验设计
1. **多源真实复杂地理场景验证**：
   - *情境 1（硬化路穿过低洼湿地）*：检验铺装道路与天然土壤分离机制，验证硬化公路是否被错误截断，同时确保公路两侧湿地翻浆被可靠规避；
   - *情境 2（林间天然狭窄通道）*：检验 3m 窄路保留与开阔度软偏好，验证算法能否在无其他通道时稳定通过可用窄道，在有替代空间时优先选宽；
   - *情境 3（横坡阶地与陡降盲坡）*：检验纵横坡严格解耦，验证算法能否主动规避 $20^\circ$ 侧倾横切路线，沿缓坡与阶地平稳展线；
   - *情境 4（暴雨后汇水区泥沼）*：检验 API 与 TWI/HAND 水分重分配，验证路线能否在低洼翻浆区前稳健转向高地或脊线骨干走廊。
2. **消融实验（Ablation Study）**：
   - 移除父格内部连通分量保留（退化为布尔 OR）：统计宏观假连通率与细层重规划失败率；
   - 移除自适应扩展（强制固定 1-ring）：统计低代价优质可行走廊被误杀的比例；
   - 移除横坡严格解耦（仅按标量坡度评价）：横坡超标高危里程增加情况；
   - 移除物理里程连续积分（退化为离散格元累加）：在不同分辨率采样下的代价漂移度。
