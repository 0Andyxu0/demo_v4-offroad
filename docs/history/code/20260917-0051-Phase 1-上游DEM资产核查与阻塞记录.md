## 2. 已完成内容

### 2.1 新增脚本

`scripts/validate_dem_asset.py`

功能：

- 打开 GeoTIFF 并输出 CRS、范围、分辨率、nodata、数据类型；
- 统计有效像元、nodata 比例、数值范围；
- 判断栅格是否像原始高程 DEM；
- 返回 0 表示通过，1 表示数据不可用，2 表示无有效像元。

### 2.3 本地 DEM 资产实测

被测文件：`D:\Workspace\demo_v1\data\dem_nanjing.tif`

```text
size: 3156 x 4971
crs: EPSG:4326
bounds: 118.36E-119.24E, 31.23N-32.61N
res: 0.0002778 deg
nodata: -32768
valid_pixels: 8,144,850 / 15,688,476
nodata_ratio: 48.08%
value_min: 0
value_max: 255
value_mean: 25.68
```

结论：**该文件不是可用的原始高程 DEM**。有效值范围 0-255 且 nodata 比例约 48%，更像经过拉伸/可视化的栅格，不能直接用于 GRASS r.watershed。
