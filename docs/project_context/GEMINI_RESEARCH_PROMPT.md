### 2. 固定需求，避免偏题

**使用 DEM、地物 TIF 或 SHP、遥感图像、土壤类型和土壤含水静态数据，辅以制作静态地图时的真实气象修正，服务于越野环境有人驾驶车辆的路线规划。** 数据是否已接入，以工程材料为准。

允许格网离散造成频繁小折线，驾驶员会局部修正；不要改成 UAV/无人 UGV 的平滑轨迹跟踪、自主控制或精确连续扫掠课题。允许小折线不等于忽略真实障碍、通道宽度和车辆通过能力。

气象在制图或更新地图时修正通行条件，同一场景内固定使用；不同气象可形成多个静态场景，不默认研究行驶中的动态天气控制。

关注整条路线的可用性、通道连续性、瓶颈、困难路段分布和合理绕行，而非仅求某个搜索代价最小。**误差平差、不确定性分析、形式化完备性和严谨性门禁只能作必要验证支撑，不作为主要创新方向。**
