## 1. 结论摘要

当前没有发现通过降低 H3 分辨率、把核心数值由 `float64` 改成低精度类型、删除物理代价字段等方式直接换取速度。向量化、列式读取、延迟路径解析和减少 Python 对象构造，原则上属于实现级等价优化。

真正需要验证的风险集中在搜索完整性与交付语义，而不是浮点数值精度：

1. 每个相邻父格最多保留 8 个边界端口，可能截掉可达或更优的微观连接。
2. 离线表缺记录时，负向旁路可能把“未预计算”当作“不可达”。
3. A* 只保证在已构造的受限宏观图上最优，不能据此证明等价于完整细网格全局最优。
4. 离线端口对只用车辆指纹做运行期准入，尚未完整绑定静态输入、拓扑、factor model 和 schema 版本。
5. fast-five 不在候选生成阶段展开环境压力情景；定向走廊修补和软化独立备份门禁也缩小了原始问题的约束范围。

因此，现阶段更准确的判断是：**尚无证据表明底层数值数据结构被降精度，但已有代码证据表明搜索空间和路线交付保证被收缩。收缩是否造成不可接受的路线质量损失，必须通过差分实验量化。**

## 2. 性能基线边界

现有报告不能组合成一条严格的 `448s → 30.78s` 因果链：

| 数据 | 实际含义 | 限制 |
| --- | --- | --- |
| `417.376321s` | fast-five 之前一次历史运行；其中 `candidate_search_s=385.737291s` | 不是 `3fbff57` 自身的实测基线 |
| `141.786592s` | `fast_five_v1` 冷运行产物；`fine_search_calls=58,541` | 对应 fast-five 阶段，不代表当前架构 |
| `124.184496s` | fast-five 暖机中位数，P95 为 `133.926397s` | 暖机结果，且 30 秒门槛未通过 |
| `448.18s` | Phase E 报告中的“fix 分支基线”均值 | 报告表格不能重新标记为 `3fbff57` |
| `162.10s` | Phase E 中 route1 升级后结果 | 与当前 30.78 秒的路线坐标相同，适合做后半段参考 |
| `30.780406s` | 当前 tier 脚本中第三个执行的 2km 路线 | 同一进程已先跑 500m、1000m，不能称为独立进程冷启动 |

当前 `scripts/benchmark_tiers.py` 依次在一个 Python 进程内执行三条路线；2km 结果记录了 312 次基础缓存命中。因此 `30.78s` 是有效的顺序运行观测值，但不是经过隔离证明的冷启动指标。

## 3. 精度维度定义

为避免把不同问题都称为“精度下降”，后续统一使用以下术语：

| 维度 | 含义 | 当前初判 |
| --- | --- | --- |
| 数值精度 | 同一节点、边、路径上的物理量和目标值是否保持等价 | 未发现主动降精度；已有 `float64` 和 `1e-6` 等价测试 |
| 空间精度 | H3 分辨率、原始栅格支持尺度和路径细格序列是否被粗化 | 未发现 H3 分辨率降低 |
| 搜索完整性 | 优化后是否仍覆盖原本可达的端口、走廊和候选路线 | 存在高优先级风险 |
| 最优性 | 优化结果相对完整搜索的目标值差距 | 尚未建立同输入 oracle 对照 |
| 物理有效性 | 路线是否通过地形、车辆、几何和环境约束 | 当前 2km 产物报告无几何有效候选 |
| 战术完整性 | 核心角色、独立备份和候选多样性是否满足门禁 | 独立备份已被软化 |
| 证据完整性 | 离线资产是否与当前输入和模型严格同代 | 指纹契约不完整 |

## 4. 潜在问题登记

### P-01：边界端口固定截断为 8 个

- **等级**：高
- **性质**：已确认存在的搜索空间限制；损失程度待实验
- **代码证据**：`routing_index.py` 中 `MAX_BOUNDARY_PORTS = 8`；`_boundary_ports()` 按 H3 字符串排序遍历，收集到 8 个后立即返回。
- **问题**：保留的是排序后的前 8 个连接，不是物理代价最优、连通性最关键或几何分散度最高的 8 个连接。
- **可能后果**：
  - 截掉唯一可穿越窄通道；
  - 截掉成本更低的边界连接；
  - 降低候选路线多样性和独立备份成功率；
  - 与 P-02 组合后把被截断连接固化为“不可达”。
- **不能据此直接断言**：当前真实路线一定选错；需要比较 `8/16/32/不限` 四档端口集合。

### P-02：负向缓存旁路可能把“未记录”解释为“不可达”

- **等级**：最高
- **性质**：代码语义已确认；是否产生真实假阴性待实验
- **代码证据**：`portsmap.py::_get_or_compute_source_pairs()` 在父格与目标 profile 被视为离线覆盖、但当前 source 没有离线记录时，可直接令 `base_pairs=()`，跳过在线 `_fine_tile_search()`。
- **合理前提**：离线表对相关父格、profile、source 必须完整，且“无记录”只能表示真实不可达。
- **当前未被完全证明的前提**：
  - source 没有被 P-01 的端口上限排除；
  - Parquet 构建、注册和读取没有缺片；
  - 离线资产与当前静态输入、拓扑和 factor model 完全同代；
  - profile 名称回退没有发生错误覆盖。
- **可能后果**：合法端口对不进入宏观图，造成假不可达、次优路线或候选角色缺失。

### P-03：“A* 可采纳”不能推出“完整细网格全局最优”

- **等级**：高
- **性质**：现有文档结论过度
- **事实边界**：可采纳启发式能够保证在当前宏观图上的最优性。
- **限制来源**：粗层骨架、走廊宽度、八端口上限、离线表覆盖、负向旁路和有限定向修补都在 A* 之前改变了图。
- **可能后果**：算法在受限图上正确收敛，但完整细网格中仍存在未进入图的更优路线。
- **正确表述**：当前实现最多能主张“受限宏观图内最优”，除非差分实验证明该图在规定场景下保留了完整搜索的最优解。

### P-04：离线端口对资产身份绑定不足

- **等级**：最高
- **性质**：已确认的契约缺口
- **代码证据**：
  - `offline_pairs.py` 只把 `vehicle_hash` 写入 Parquet metadata；
  - `register_port_pairs()` 只接受并登记 `vehicle_hash`；
  - `route_planning.py` 加载端口对时主要按车辆指纹准入。
- **缺失身份**：`static_input_hash`、`graph_topology_hash`、`factor_model_hash`、端口选择参数、算法/schema 版本。
- **可能后果**：车辆相同但地形、拓扑、factor 配置或端口生成算法变化时，旧路径和旧成本仍可能被加载；结合 P-02 后会同时产生错误正命中和错误负命中。

### P-05：fast-five 在候选生成阶段忽略环境压力情景

- **等级**：高
- **性质**：已确认的搜索广度缩减；自 `3fbff57` 已存在
- **代码证据**：`route_planning.py` 在 `fast_five` 为真时向 `DeterministicParetoPlanner` 传入空的 `environment_pressures`。
- **问题**：环境压力只在候选已经产生后参与评价，无法召回“常态不优、雨天或高含水率下才最优”的路线。
- **可能后果**：环境鲁棒候选缺失；后评价不能弥补候选生成阶段未搜索到的路径。
- **需要区分**：这是 `417s → 124s` 阶段的重要折中，不是当前架构升级分支独有。

### P-06：定向走廊修补是局部恢复，不是完整扩张

- **等级**：中高
- **性质**：已确认的搜索范围限制；实际影响待实验
- **问题**：有限次数、有限父格的定向扩张只解决检测到的连通瓶颈。找到可行路径后，不会继续系统搜索更远但成本更低、风险更小或更独立的路线。
- **可能后果**：可达率提高但最优性、多样性和独立性仍低于完整 2-ring 或更宽走廊。
- **当前 2km 证据**：运行发生 1 次定向修补、增加 10 个父格，最终仍报告独立备份不可用。

### P-07：独立备份由硬门禁变为可选告警

- **等级**：高（若独立备份属于业务硬要求）
- **性质**：已确认的交付语义变化，不是数值精度问题
- **代码证据**：`require_independent_backup` 默认值为 `False`；缺失时返回 `INDEPENDENT_BACKUP_UNAVAILABLE`，而不是规划失败。
- **当前产物证据**：2km `route_plan.json` 的第五条候选 `roles=[]`，并包含 `INDEPENDENT_BACKUP_UNAVAILABLE`。
- **可能后果**：系统更容易“成功返回”，但不能等同于稳定交付五个完整角色或五条有效路线。

### P-08：性能成功与物理/几何有效性没有绑定

- **等级**：高
- **性质**：当前产物已确认
- **当前产物证据**：30.78 秒的 2km 结果包含 `NO_GEOMETRY_VALID_CANDIDATE`。
- **问题**：候选对象数量、核心角色存在和规划耗时都不能替代几何有效性验收。
- **可能后果**：性能门槛通过，但没有可被车辆轨迹执行的路线。

### P-09：未知土壤回退可能偏乐观

- **等级**：中高
- **性质**：数据语义风险；不一定由本轮性能优化引入
- **问题**：未知 code/name 最终可能回退到 `loam` 和可通行分类，相当于把“证据未知”转换成“工程上可通行”。
- **可能后果**：在缺少地勘证据的区域产生假阳性通行路线。
- **正确处理原则**：未知应保留为未知、降低置信度或触发保守门禁，不能仅凭默认映射宣称物理有效。

### P-10：`_fast_create` 绕过数据类运行时校验

- **等级**：中
- **性质**：已确认的防御性校验削弱
- **代码证据**：快速构造使用 `object.__new__` 和 `object.__setattr__`，不执行 `__post_init__` 中的有限性、非负性、区间顺序和置信度范围检查。
- **正面证据**：向量化与标量实现已有样本级字段等价测试，核心数组保持双精度。
- **剩余风险**：上游出现 NaN、无穷大、越界或字段错位时，错误可能更晚才暴露。
- **判断**：不是主动降低数值精度，但降低了异常数据的即时可发现性。

### P-11：图指纹缓存只用元素数量判断是否可复用

- **等级**：中
- **性质**：可变图场景下的完整性风险
- **代码证据**：`static_input_hash()` 只比较 cell 数量，`graph_topology_hash()` 只比较 edge 数量后便可能返回缓存值。
- **可能后果**：图内容原地变化但数量不变时，得到过期指纹，使缓存或持久化契约误判同代。
- **限制**：如果图对象构造后严格不可变，则该风险不会触发；需要用突变测试确认实际生命周期。

### P-12：现有 30.78 秒结果不是隔离冷启动

- **等级**：高（针对性能结论），不属于路径精度问题
- **性质**：已确认的测量设计缺陷
- **代码证据**：`benchmark_tiers.py` 在同一进程依次执行 500m、1000m、2000m；全局基础端口对缓存跨路线存活。
- **当前产物证据**：2km 记录 `base_pair_cache_hits=312`。
- **可能后果**：把进程内缓存收益写成冷启动收益，夸大部署首请求性能。
- **正确术语**：该结果应称为“顺序批次中的第三次运行”，直到独立进程复测。

## 5. 当前已有的安全性证据

以下证据支持“没有直接降低底层数值精度”，但不能替代搜索完整性实验：

- routing index 的核心数值字段仍为 `float64`。
- 细网格和粗网格分辨率仍按当前请求使用 `res_fine=14`、`res_coarse=11`。
- 离线端口对持久化完整 H3 路径和双精度 cost；命中路线会延迟解析完整路径。
- 向量化测试逐字段比较标量实现，目标容差为 `1e-6`。
- 带局部 blocked/penalty 的场景会回退在线计算，没有直接套用纯基础 profile 的离线结果。
- 返回路径仍经过连续性检查和路径指标重新评价。

这些只能证明“同一路径上的计算大体等价”，不能证明“优化后仍会搜索到同一条路径”。

## 6. 风险优先级

| 优先级 | 问题 | 原因 |
| --- | --- | --- |
| P0 | P-02 负向旁路、P-04 资产身份 | 能直接产生假不可达或使用过期路径，且当前缺少完整保护 |
| P0 | P-01 八端口截断 | 是负向旁路成立前提的一部分，可能从源头删除合法连接 |
| P1 | P-03 全局最优表述、P-05 环境候选缩减 | 影响路线质量结论和极端环境适用性 |
| P1 | P-07 独立备份、P-08 几何有效性 | 当前产物已经暴露交付语义不完整 |
| P1 | P-12 冷启动测量 | 直接影响 30 秒性能结论是否成立 |
| P2 | P-06 定向修补、P-09 土壤默认 | 影响特定地形和证据不足区域 |
| P2 | P-10 快速构造、P-11 指纹缓存 | 主要在异常输入或可变图生命周期触发 |

## 7. 当前不能宣称的结论

在完成差分实验前，不应宣称：

- `3fbff57` 的端到端基线为 448.18 秒；
- 30.78 秒是严格冷启动结果；
- 当前 A* 与完整细网格搜索数学等价；
- 503 个测试通过证明不存在精度或路线质量回退；
- 返回 5 个候选对象等价于交付 5 条角色完整、几何有效、相互独立的路线；
- 离线表缺记录必然表示物理不可达。

下一步应按《20260921-1241-性能精度完整性验证实验搭建方案.md》建立同输入、隔离进程、可关闭单项优化的差分验证。
