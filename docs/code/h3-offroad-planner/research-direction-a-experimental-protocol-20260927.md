第一轮只需要：

1. **A*pex：** 原始图上的近似搜索基线。
2. **PE-GA*pex：** 最接近的分区预处理强基线。
3. **BOA*：** 小图精确前沿真值；不能把它比近似算法慢直接当作创新。
4. **待研究方法：** 同图、同代价、同近似要求下，改变摘要生成或细化机制。

双目标 CH 放在多查询预处理补充组，A-A*pex 放在 anytime 扩展组。当前 demo 用于工程差异分析，不替代强基线。

## 2. 先检验一个明确假设

> 在同一地图或环境快照只服务有限次查询时，预先生成大量边界端口连接的成本可能难以摊销；按查询需求生成摘要，可能在相同近似保证下减少总计算成本。

PE-GA*pex 预处理涉及簇边界连接，其部分展开机制减少查询阶段生成的后继。**推迟后继展开与推迟连接摘要生成是不同干预点。** 后者值得检查，但不能直接宣布新颖：惰性搜索已有相关研究，仍需核查先行方法并证明正确性。

这是假设。若大部分摘要都会被反复使用，或在线检查过于昂贵，按需方案可能更差。

### 2.1 写新算法之前的五项诊断

| 量 | 定义与作用 |
|---|---|
| 总摘要数 P | 预处理产生的有向端口连接摘要；多条前沿代表另计数量 |
| 已访问摘要比例 | 查询过程中读取或生成过对应后继的摘要数 / P；不是必然可以安全省掉的比例 |
| 返回路径使用比例 | 返回解实际使用的摘要数 / P；不能代替已访问比例 |
| 摘要构造耗时 | 与分区、I/O 和查询分开，判断可优化成本 |
| 边界规模分布 | 每簇端口数的中位数、p95、最大值，解释组合数量与耗时 |

从搜索过程中采集，而不是只看最终推荐路径。正式计时关闭重型日志，记录日志开销。

形成预期的成本分解为：

$$
T_{\mathrm{eager}}(Q)=P_0+\sum_{q=1}^{Q}t_q,\qquad
T_{\mathrm{lazy}}(Q)=L_0+\sum_{q=1}^{Q}(\ell_q+m_q).
$$

$P_0$ 是完整预处理，$L_0$ 是按需方案的必要准备，$\ell_q$ 是搜索与证书检查，$m_q$ 是首次摘要构造。不能把 $m_q$ 藏进“已有缓存”。省下的构造成本大于新增检查成本，才有速度收益。这是诊断模型，不是已经证明的复杂度结论。

## 3. 实验 0：先复现原作者程序

**目的：验证实验装置，暂不证明新算法优越。**

1. 固定仓库 commit、编译器、优化级别、依赖及数据哈希，先运行未改动作者版本。
2. NY 上跑通，再扩展 COL、NW、CAL。直接读取原始图，不先转成 H3。
3. 首先比较 ε=0.01 的 A*pex 和 PE-GA*pex；小实例用 BOA* 检查真值。
4. 从源码核对启发函数计时、输出路径／代价格式和 ε 的传递。README 命令只是入口，本次未验证其可执行性。
5. 重建原论文同类表格：图规模、索引规模、预处理时间、查询时间、解出数量。跨机器比较相对趋势，不要求绝对秒数与原文相同。

[A-pex](https://github.com/HanZhang39/A-pex)含 BOA*、PP-A*、A*pex；[PE-GA*pex 仓库](https://github.com/CRL-Technion/BOSP-PE-GApex)说明其查询端基于 A*pex 的 C++ 实现，预处理主要用 Python。共享底层实现是可行策略，但本次没有编译验证。

**退出条件：** 输入不一致、路径重算错误或原算法未正确运行时，先处理复现，不开展性能归因。

## 4. 实验 1：继承论文的公共基准主对照

下表是**建议冻结的本课题协议**。新增样本划分、重复次数和内存预算不是学界统一标准。

| 项目 | 建议设置 |
|---|---|
| 图与划分 | NY 开发；COL、NW、CAL 作为冻结后的保留测试 |
| 目标 | 原始距离、时间，不人为修改权重创造优势 |
| 主质量条件 | 两目标 ε=0.01 |
| 敏感性 | ε∈{0.001,0.005,0.01,0.1}，各算法使用相同向量 |
| 查询 | 优先使用作者固定 OD；无法取得时新生成并发布 100 个 OD，标记新测试集，不称原文复现 |
| 开发查询 | NY 上另生成 20 个，与保留查询不重合；种子 20260927 |
| 正式限时 | 每查询 1800 秒；初始通路测试可用 300 秒，结果不混算 |
| 内存 | 登记硬件后统一冻结上限；硬件允许时建议先用 8 GiB，不按算法分别调整 |
| 线程 | 主实验单线程；固定 CPU 使用策略，记录硬件与功耗模式 |
| 重复 | 确定性计时重复 3 次取中位数；随机预处理另用 5 个固定种子 |
| 失败 | 分别记录不可达、超时、内存失败，不删除不利实例 |

补充 OD 在预先确定的可达节点集合内按固定种子抽样，排除相同起终点与重复 OD。距离分层作为额外实验时，先建立候选池，再按单目标最短路距离分层；不能只根据多目标运行时长挑选有利困难样本。

主对比是**相同 ε 下，到满足完整返回条件的时间及成功率**。ε=0.01 主结果和新增敏感性结果分开，不将后者写成原论文所有图的原始设置。

## 5. 实验 2：检验收益机制

### 5.1 固定分区，只改变摘要生成方式

保留作者分区、底层代价、启发函数、近似合并规则与部分展开，先只改变摘要何时生成：

| 版本 | 构造方式 | 要回答的问题 |
|---|---|---|
| B0 | 原 PE-GA*pex 的完整预构造 | 强基线 |
| B1 | 简单按需构造，保留正确的乐观表示 | 单纯推迟构造是否有效 |
| B2 | 待提出的证书驱动构造／细化 | 新准则是否超过简单惰性策略 |

**B2 必须比较 B1。** 仅超过 B0 而未超过 B1，不能把所有收益归于复杂新机制。若 B1 尚缺正确性规则，它也是待研究的版本，不是已存在可运行的基线。

### 5.2 把查询次数作为实验轴

$Q\in\{1,5,10,25,50,100\}$。同一组 100 个不同 OD 使用 5 个冻结的随机排列，对比每个排列的前 Q 个查询。每个排列开始时清空方法特有的索引／查询状态，只复用过去查询信息，不预知未来 OD。

每个算法报告：

- **冷开始总时间：** 从相同原始图开始，到完成前 Q 个查询；包含预处理、在线构造和查询准备。
- **索引已有时的查询时间：** 单列，回答长期部署问题。
- **峰值内存与累计摘要数：** 包含惰性缓存。

不把同一个 OD 重复一百次当作一百次新任务，也不允许新方法预知序列而让基线承担通用预处理。

### 5.3 两项受控敏感性实验

第一项固定地图和代价，仅改变预先选定的分区参数，观察边界规模、摘要数和耗时。它保持同一个图搜索问题。

第二项固定拓扑与第一目标，令第二目标由正比例项乘以可控正噪声构成，分别使用局部连续与空间打散的噪声排列。相同噪声值集合和固定种子下，报告实际目标相关性与空间分布，而不是只报输入参数。它检验相关性／空间组织的影响，不证明真实越野性能。

所有参数在开发集冻结。原始未修改 DIMACS 结果必须保留，不能只展示特意构造的有利情况。

## 6. 实验 3：GIS 图上的外部验证

### 6.1 所有算法读同一张完整研究区图

冻结研究区范围、H3 层级、车辆和环境快照，导出有向邻接及边代价：

- 第一目标采用项目边距离；第二目标优先试用非负、可加的地形风险代价。先验证最终路线指标确实等于逐边求和。
- 所有算法统一删除禁行边；最小通行裕度先作硬阈值，不能当成加法目标。
- 零风险边必须核对作者实现支持情况；不能擅自每边加常数，因为这会改变对路径边数的偏好。
- 如果作者代码读取整数，公开量化尺度和溢出检查，所有方法使用相同量化图，另检验量化对原始代价的影响。

项目加权边代价入口见 [portsmap.py](D:/Workspace/demo_v4/src/h3_offroad_planner/portsmap.py:124)。这是接入线索，不表示实验导出器已存在。

**固定参考图边界。** 不允许各算法采用不同自动走廊。裁剪子图的真值只属于该子图，不宣称覆盖地图外部路径。

### 6.2 可行性研究的起始规模

建议 3 个互不重叠地形区域：1 个开发、2 个保留测试。每区约 1 万、5 万、20 万节点的三个嵌套范围，各冻结 50 个可达 OD；规模不满足时报告实际值，不复制节点凑数。

这些是工作量可控的**起始建议**，不是 SCI 样本标准。嵌套范围相关，不能当成九个独立区域。依据方差、退化情况及论文主张，再决定扩大独立区域数。

最小图求精确前沿，大图与相同近似基线对比。固定分辨率、扩大地域范围，与固定范围、改变分辨率属于不同实验，避免混淆算法扩展性与数据精度变化。

## 7. 固定质量后，如何判断更好

### 7.1 小图覆盖误差

严格正参考代价下，精确前沿 $P^*$ 与返回集合 $S$ 的误差为：

$$
e(S;P^*)=
\max_{p\in P^*}\min_{q\in S}
\max\left(0,\max_i\left[\frac{c_i(q)}{c_i(p)}-1\right]\right).
$$

这与 A-A*pex 的近似误差定义一致。零参考分量改用覆盖不等式检查；无返回解作为失败记录。[定义来源](https://ojs.aaai.org/index.php/SOCS/article/download/31556/33716)

ε=0.01 组必须先满足路径可行、代价正确、覆盖合格。精确算法另列，说明其完成的是更严格任务。

### 7.2 大图区分三种证据

1. 算法实际成立的理论证书。
2. 相对所有算法结果非支配并集的经验误差，标记 pooled reference，不能称真值。
3. 在共用原始图上的返回路径重算，排查解包、缓存与量化错误。

修改剪枝或近似表示后，有限实例的测试通过不替代证明。

### 7.3 统一计时与统计

$$
T_{\mathrm{session}}=
T_{\mathrm{load}}+T_{\mathrm{preprocess}}+
\sum_q(T_{\mathrm{heuristic},q}+T_{\mathrm{search},q}
+T_{\mathrm{materialize},q}+T_{\mathrm{unpack},q}).
$$

各阶段计时互不重叠。求参考真值是离线评估成本，不计入被测求解器时间。若原论文只计搜索核心，同时提供那一列，并另外报告完整会话成本。

逐 OD 配对计算耗时比，同时报告成功率、共同成功子集、失败表和各地图结果。共同成功的比值不能代表全体实例。采用超时惩罚汇总时固定规则，并保留原始成功率。

重复运行反映计时噪声，OD 反映实例差异，独立区域支持跨区域判断；置信区间应尊重层次，不把重复运行当成独立地形样本。

## 8. 继续或停止的标准

以下是**课题内部建议门槛**，不是 SCI 录用标准，也不是承诺结果。

| 观察结果 | 研究判断 |
|---|---|
| 覆盖违规、不可行路径或代价错误 | 停止性能结论，先修正正确性 |
| 几乎所有摘要都会被使用且构造成本低 | “减少无用摘要”动机不足，不先开发复杂方案 |
| B1 取得全部收益，B2 无额外作用 | 收窄贡献，核查简单方法是否已有研究 |
| 同 ε、同成功率，冻结负载下总成本稳定下降且超过噪声 | 有继续价值；可暂以总成本下降 20% 为内部实用目标 |
| 只赢挑出的 OD 或自造代价 | 仅支持局部机制现象 |
| Q 小时快、Q 大时慢 | 报告交叉点；若负载有应用依据，可定位有限查询方法 |
| C++ 新实现只胜过 Python demo | 不能归因于算法 |
| 公共基准一般，独立越野图稳定受益且有消融解释 | 可主张面向越野结构的专门方法，不宣称通用最优 |

主指标与负载范围在正式测试前确定。没有“一份快照通常服务多少次查询”的记录时，Q 实验只是敏感性分析，不能声称低 Q 已是典型使用场景。

## 11. 结论

先把“大范围有界分层越野规划”收缩为一个实验能够回答的问题：**同样近似要求下，哪些预计算可避免，节省是否超过在线验证成本，优势在哪种负载和图结构上成立。**

这条路线有公共数据、作者程序、可继承指标和明确失败条件。实验能判断构想是否值得继续，不能保证新方法一定超过已有工作。
