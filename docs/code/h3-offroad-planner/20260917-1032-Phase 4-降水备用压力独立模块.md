## 2. 新增模块

```text
src/h3_offroad_planner/weather_fallback.py
```

功能：

- precipitation_pressure(precipitation_24h_mm, api_reference_mm)
  - 将 24h 降水映射到 [0, 1] 压力；
  - 超过参考值时截断为 1.0。
- resolve_precipitation_fallback(snapshot, api_reference_mm)
  - 根据环境快照和配置返回：
    - pressure
    - pressure_basis
    - warnings

## 3. 行为

| 输入 | 结果 |
|---|---|
| 降水 5mm，参考 10mm | pressure=0.5 |
| 降水 10mm，参考 5mm | pressure=1.0 |
| 快照 degraded | 返回 None + ENVIRONMENT_DATA_DEGRADED |
| 未配置 api_reference_mm | 返回 None + ENVIRONMENT_PRESSURE_UNCALIBRATED |
