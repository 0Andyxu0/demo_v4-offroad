## 4. 模块功能说明

- `factor_model.DecisionConfig.require_independent_backup`
  - false：物理单通道时允许输出其余四角色并告警；
  - true：任务明确要求韧性时，无独立备选即失败。
- `route_planning._routing_role_warnings`
  - 负责四个核心角色强制校验；
  - 负责独立备选缺失时的告警/失败策略。
