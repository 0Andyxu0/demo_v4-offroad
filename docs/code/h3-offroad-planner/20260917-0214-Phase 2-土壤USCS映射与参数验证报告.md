### 2.2 合理性说明

- 水稻土及各种水稻土亚类：以粘土/粘壤土为主，映射为 CL/ClLo 合理；
- 黄褐土、黄棕壤、红壤、棕红壤等：多为粘性土，映射为 CL 合理；
- 冲积土、潮土、灰潮土：多为粉质壤土，映射为 ML/SiLo 合理；
- 石灰土、紫色土、基性岩风化土：按保守粘性土处理为 CL/Lo；
- 沼泽土、水域、城区：设置为不可通行。

## 3. 参数设置核对

### 3.1 static_factor_model.yaml

```yaml
soil_by_uscs:
  SW: 0.90
  SP: 0.85
  SM: 0.70
  ML: 0.60
  CL: 0.55
  CH: 0.40
  MH: 0.35
```

当前映射产生的 USCS 为 CL、ML、SM，均已覆盖，参数顺序符合常识：

```text
砂土 > 粉土 > 粘土
```

### 3.2 Bekker 参数

Bekker 模块支持：

```text
SW SP SM ML CL CH MH
```

当前映射只使用 CL、ML、SM，均在支持范围内。

土质分组：

```text
ClLo -> clayloam
Lo / SiLo / SaLo -> loam
```

均已在 Bekker 参数表中覆盖。

## 4. 仅有土壤类型名称区域的替代方案

当区域只有土壤类型名称、没有完整 USCS 映射表时，`_soil_texture_mapping` 会按以下优先级处理：

1. 显式土壤代码表；
2. 土壤名称关键字：
   - 水/湖/江/城区 -> 不可通行；
   - 沼泽 -> 不可通行；
   - 砂 -> SaLo/SM；
   - 粘/水稻 -> ClLo/CL；
   - 潮/冲积 -> SiLo/ML；
   - 石灰/紫/红/棕/黄/暗 -> Lo/CL；
3. 保守默认：Lo/CL，可通行。

这样即使遇到未知代码，也能给出可解释、可通行的工程推定，而不是直接缺失。
